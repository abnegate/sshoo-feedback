# SSHoo feedback

Bug reports and feature requests for [SSHoo](https://sshoo.app), the local-first SSH client for Android. The app's source is private; this repository is only the public issue tracker.

- **Found a bug?** [Report it](https://github.com/abnegate/sshoo-feedback/issues/new?template=bug_report.yml).
- **Want something?** [Request a feature](https://github.com/abnegate/sshoo-feedback/issues/new?template=feature_request.yml).
- **Questions about Pro, pricing or privacy?** Check the [FAQ](https://sshoo.app/faq) first.
- **Security problem?** Don't open an issue. Email support@sshoo.app instead (see [SECURITY.md](SECURITY.md)).

Issues are public. Never post hostnames, IP addresses, usernames, keys, passwords, tokens or unredacted logs.

Get SSHoo on [Google Play](https://play.google.com/store/apps/details?id=com.abnegate.sshoo).
